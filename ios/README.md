# ЛКЭОС для iPhone

Версия 1.3, минимальная система iOS 17.0. Приложение соединяется с ЭОС Калужского филиала и ЛКС МГТУ через встроенные окна WebKit.

## Запуск из Xcode

Откройте `LKEOS.xcodeproj` на Mac в Xcode 15 или новее. Выберите цель LKEOS, затем в Signing & Capabilities укажите свою Team. Если идентификатор приложения занят, задайте уникальный Bundle Identifier. Выберите подключённый iPhone с iOS 17 или новее и нажмите Run. Для проверки интерфейса можно выбрать iPhone Simulator.

Готовый IPA предназначен для подписи под ваш iPhone. Исходная техническая подпись ad hoc подтверждает целостность пакета. Для установки на обычный iPhone требуется подпись Apple и профиль подготовки. Вы также можете подписать IPA своим средством установки приложений.

## Первый вход

Откройте «Профиль» и выберите локальный профиль. Для автоматического входа сохраните логин и пароль отдельно для ЭОС и ЛКС. Данные хранятся в Связке ключей на этом iPhone. Если вводите пароль только на официальной странице, приложение может повторно использовать действующую сессию.

При запуске ЭОС открывает персональные курсы. «Успеваемость» загружает ведомость при открытии раздела. Сессии ЭОС и ЛКС раздельны для каждого профиля. Сохранённые записи из Windows не переносятся.

Полная таблица доступна в разделе «Мои работы». На главной рядом с календарём находятся четыре последние открытые работы текущего профиля. В боковой карточке доступны сроки, оценка, методички и редактор файлового ответа. Материалы и лабораторные открываются из курса. В редакторе ответа нажмите «Выбрать файлы», затем «Выбрать на iPhone». Проверьте вложения и нажмите «Сохранить ответ» для отправки в ЭОС.

## Проект

Нативная часть на Objective-C отвечает за окна WebKit, раздельные хранилища сайтов, учётные записи и выдачу загруженных файлов через системное меню. Папка Web содержит мобильный интерфейс. В PortalScripts находятся обработчики официальных форм и ответов ЭОС и ЛКС. Для сборки в Xcode внешние пакеты не требуются.
