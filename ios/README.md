# ЛКЭОС для iPhone

Лабораторные, расписание и оценки из ЭОС и ЛКС в одном приложении. Версия 1.0, сборка 6. Требуется iPhone с iOS 17 или новее.

**[Скачать IPA](https://github.com/Nexerium/LKEOS/releases/download/v1.0/LKEOS-1.0-iphone.ipa)**

### Установка

Подпиши IPA для своего iPhone с помощью средства установки приложений. Для сборки из исходников открой `LKEOS.xcodeproj` в Xcode на Mac, выбери свою Team в **Signing & Capabilities** и запусти цель **LKEOS** на устройстве. Если идентификатор приложения занят, укажи свой Bundle Identifier.

### Что внутри

* **Обзор.** Пять последних открытых работ и календарь фиксированной высоты с событиями, номером недели и пометкой «числитель» или «знаменатель».
* **Мои работы.** Открой карточку, посмотри оценку и методичку, прикрепи файл и нажми «Сохранить ответ». Личные галочки и отметку о закрытом предмете можно изменить вручную. Скрытие предмета в работах сохраняет его в списке курсов.
* **Учёба.** Расписание ИУК6-51 по подгруппам, успеваемость по неделям и результаты сессии по семестрам. Повторное открытие показывает загруженные данные. За свежими данными нажми «Обновить».
* **Профиль.** Один логин МГТУ для ЭОС и ЛКС, отдельные сессии для каждого профиля и пароль в Связке ключей iPhone. Здесь можно настроить автовход, сменить тему, создать, переименовать или удалить профиль.

При автовходе ЭОС подключается на старте, а ЛКС запрашивает вход при открытии личных оценок. Публичное расписание открывается сразу. Во время входа можно нажать «Отмена». Если он затянулся, появится кнопка «Открыть форму входа».
