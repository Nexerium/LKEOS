Первый публичный выпуск ЛКЭОС для Windows x64. Приложение объединяет ЭОС Калужского филиала МГТУ и ЛКС в одном окне.

### Что можно делать

* Открывать лабораторные прямо из «Моих работ» или из пяти недавних работ на главной. В карточке доступны сроки, методички, прикреплённые файлы и оценка.
* Загружать отчёты в ЭОС, отмечать выполненные работы для себя и скрывать предметы в списке работ.
* Смотреть успеваемость по неделям, результаты сессии и расписание группы ИУК6-51 с разбивкой по подгруппам, числителю и знаменателю.
* Переключать светлую и тёмную темы, создавать профили и включать автовход с учётной записью МГТУ.

### Как запустить

Скачайте **[LKEOS-1.0-win-x64.exe](https://github.com/Nexerium/LKEOS/releases/download/v1.0/LKEOS-1.0-win-x64.exe)**, откройте приложение и войдите через МГТУ. Для работы нужен Microsoft Edge WebView2 Runtime. Среда .NET включена в EXE.

**[Исходники версии 1.0](https://github.com/Nexerium/LKEOS/releases/download/v1.0/LKEOS-1.0-source.zip)** доступны отдельным архивом. Инструкция по сборке есть в README.
